# Troubleshooting

| Symptom                                                                         | Likely cause                                                           | Fix                                                                                                                              |
| ------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `ConfigError: Integration tests cannot run — required configuration is missing` | `.env` absent or incomplete                                            | Copy `.env.example` → `.env`; run `npm run check-env`                                                                            |
| `ApiTransportError: … (ECONNREFUSED …)`                                         | Service down, wrong URL, no VPN                                        | Check `PII_BASE_URL`; `curl $PII_BASE_URL/health/ready`                                                                          |
| `(ETIMEDOUT/ECONNABORTED …)`                                                    | Slow network/service                                                   | Raise `PII_HTTP_TIMEOUT_MS`; check VPN                                                                                           |
| `Preflight failed: GET /health/ready -> HTTP 503`                               | Service not ready (startup, key/DB unavailable)                        | Wait or contact backend with the request ID                                                                                      |
| Every signed call → 401                                                         | Caller not registered, wrong key for the caller ID, clock/env mismatch | Confirm the registered public key matches `openssl pkey -in secrets/primary-caller.pem -pubout`; confirm `PII_CALLER_PRIMARY_ID` |
| `SignerError: … could not be parsed`                                            | Key is encrypted, not PKCS#8, or mangled newlines                      | Regenerate with `npm run keys:generate`; for inline keys use literal `\n` or Base64 of the PEM                                   |
| `SignerError: … type "rsa"`                                                     | Non-Ed25519 key                                                        | The service requires Ed25519                                                                                                     |
| Unexpected 403 on functional tests                                              | Primary caller lacks a permission                                      | Compare with `setup-guide.md` §4                                                                                                 |
| AZ-004/AZ-005 fail                                                              | Limited caller permissions differ from spec                            | Ask backend to set exactly EMAIL:SEARCH, NAME:READ                                                                               |
| `requires PII_TEST_PHONES`                                                      | No approved numbers configured                                         | Obtain approved numbers from QA lead                                                                                             |
| `DbConfigError: … DB_ENGINE=none`                                               | DB not configured                                                      | See `database-setup.md`, or exclude: `--grep-invert @db`                                                                         |
| `Row 0 of "findPiiRecords" does not match the required column aliases`          | Catalog SQL returns wrong aliases                                      | Alias columns exactly as in `database-setup.md` §3                                                                               |
| `Only read-only SELECT/WITH queries are permitted`                              | Catalog contains a write or multiple statements                        | Use a single SELECT                                                                                                              |
| Search exact-count tests fail with extra matches                                | Another run wrote the same value in the tenant                         | Emails are run-unique; for phones only inclusion is asserted. Check for a fixed `PII_TEST_RUN_ID` reused across runs             |
| BR-004 slow / rate-limited (429)                                                | Seeding 50 users                                                       | Lower workers; ask about rate limits (Q-29)                                                                                      |
| TR-001 `expires_at` out of range                                                | Clock skew between runner and server                                   | Sync NTP or raise `PII_CLOCK_SKEW_TOLERANCE_SECONDS`                                                                             |
| Tests show _fixme_                                                              | Blocked by a backend question                                          | See annotation Q-ID in `known-gaps-and-questions.md`                                                                             |
| `npm ci` warns about install scripts (esbuild/fsevents)                         | npm 11 install-script policy                                           | Harmless for this project; `npm install-scripts approve esbuild` if `tsx` scripts fail                                           |
| Need more detail on a failure                                                   | —                                                                      | `npm run test:debug -- -g <ID>`; logs are redacted                                                                               |
